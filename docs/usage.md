# 使用说明

## 本地启动

1. 安装 Node.js 20.19+。
2. 执行 `npm install`。
3. 复制 `.env.example` 为 `.env`。
4. 在 `.env` 中填写 `DECART_API_KEY`。
5. 执行 `npm run dev`。
6. 打开 `http://127.0.0.1:5173`。

## 试穿流程

选择内置服装，或上传不超过 10 MB 的服装图片。填写服装描述后启动试穿，连接后可以切换服装。结束时点击停止。

上传视频需要浏览器支持 `captureStream()`；不支持时请使用摄像头输入。

## 常见问题

- **没有画面**：确认摄像头可用、浏览器允许媒体访问，并检查网络是否支持 WebRTC。
- **无法获取令牌**：确认服务端已加载 `.env`，并检查 Decart API Key 是否有效。
- **连接后没有输出**：检查网络质量、Decart 服务状态和账户可用额度。
- **公网访问失败**：服务端默认绑定 `127.0.0.1`，需要根据部署环境配置监听地址和反向代理。
